🧬 中国科学院生物考研智能百宝箱 (UCAS Biology Data Hub)
打破考研信息差，用数据丈量上岸距离。
专为中国科学院生命科学领域考研学子打造的一站式择校、备考与数据分析平台。

💡 项目背景
中国科学院（UCAS）拥有62所生命科学培养单位，分布在全国各地，招生目录、考试科目、导师方向庞杂且高度细分。考生往往面临“信息搜集难、跨所对比难、分数线难以预测、导师方向匹配难”等痛点。

本项目作为一个前后端分离的智能数据看板，将官方散落的招生简章、考纲、分数线及导师语料进行清洗、结构化与可视化，帮助考生科学择校，精准定位，一键生成个人专属的备考白皮书。

✨ 核心功能 (Features)
01 🏢 院所全景档案
全景收录：一站式浏览中科院62所生命科学培养单位的区域分布（京区、沪区、京外等）与优势学科。

硬核难度评级：独创 Extreme, Ultra, ProMax, Pro, Plus 五档报考难度分级，直观呈现竞争烈度。

多维筛查：支持按地区、城市、代码及优势学科快速检索。

02 🔄 初试双向检索
科目反查院所：勾选“338生物化学 + 888生物学综合”，系统自动匹配所有接受该组合的院系。

精准过滤：支持学术型/专业型、统考/联培的快速筛选，直接展示研究方向与初试四门科目。

03 📊 分数线看板
历年趋势：汇总各院所近年（2024-2026）复试分数线。

分数四区间定位：输入你的目标分数，系统自动判定你的位置：危险擦线区、边缘博弈区、稳妥竞争区、高分优势区。

数据可视化：直观的柱状图展现分数线及复录比信息。

04 🧭 方向与导师库
三级探索：基于“大类 -> 细分方向 -> 具体研究内容”逐级下钻。

智能匹配：引入NLP语义分析（联合解析3089位导师方向语料与241条招生目录），根据输入的关键词或意向城市（如：Python/上海/生物医学工程），进行相关度排序匹配。

05 📝 考纲备考白皮书
个人定制：选择目标院所与专业，输入预估分数，实时对比历年线。

一键导出：自动汇总官方考纲PDF、参考书目及个人专属的“作战方案配置”，一键导出为《中科院生物考研作战白皮书.pdf》，直接作为备考行动指南。
